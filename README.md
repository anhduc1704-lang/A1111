# AI Quiz Real-Time Elimination Game

He thong tro choi trac nghiem loai truc tiep thoi gian thuc 8 cau hoi chu de Tri tue nhan tao (AI), phat trien bang Node.js, Express va Socket.IO.

## 1. Cau truc thu muc du an

ai-quiz-game/
├── public/
│   ├── index.html       (Giao dien dien thoai danh cho Nguoi choi)
│   └── admin.html       (Giao dien Bang dieu khien Quan tro / MC)
├── server.js            (Node.js + Express + Socket.IO Server & Game Logic)
├── package.json         (Khai bao goi phu thuoc)
└── README.md            (Huong dan cai dat)

## 2. Huong dan chay Localhost

1. Mo Terminal tai thu muc ai-quiz-game
2. Cai dat: npm install
3. Chay Server: npm start
4. Truy cap localhost:3000 va localhost:3000/admin
